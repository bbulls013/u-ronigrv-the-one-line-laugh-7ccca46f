A tiny deterministic program for The One-Line Laugh. It writes a single
stand-alone funny sentence to `/output/entry.txt` — an everyday
password-keeping habit whose tidy solution quietly becomes the risk.

Run it with `python3 main.py`. It uses only the standard library, needs
no network, and produces the same bytes on every run. The output is one
UTF-8 sentence, well within the 200-character gate.
